# 침전지 유동 진단 · 수시 CFD 모의 (데모)

정수장 침전지의 3차원 CFD를 AI 서로게이트로 대체해, 경계조건(기상 · 유입량 · 수위)이 바뀔 때마다 유동을 즉시 재계산하는 **의사결정지원 대시보드의 화면 개념 데모**입니다.
K-water 물종합진단처의 진단 플랫폼 안에 들어가는 한 화면을 가정했습니다.

> ⚠️ 화면의 유동장, 실측값, 모델 성능 수치는 모두 **가상값**입니다. 해석적 근사식으로 그린 그림이며 실제 CFD나 학습된 모델의 결과가 아닙니다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 운영 모드 | **상시 감시**(실측 경계조건으로 10분마다 자동 모의) / **수시 모의**(조건을 바꿔 즉시 모의) |
| 경계조건 설정 | 유입량 · 수위 · 유입 수온 · 유입 탁도(유입 경계), 풍속 · 기온(수면 경계), 풍향 · 일사 · 강수 정보. 각 입력 아래에 서로게이트 **학습범위**를 표시하고, 범위를 벗어나면 정밀 CFD 검증을 권고 |
| 시나리오 | 현재 실측 · 집중호우 예보 · 동절기 저수온 · 유입량 +30% |
| 3차원 유동 결과 | 평면 분포(수심 1.0 m)와 종단면, 유속 크기 / 탁도 / 수온 전환, 유동 벡터 표시 |
| 실측 센서 대비 | P1(유입부) · P2(중간부) · P3(위어 전단)의 실측과 예측 비교. 현재 실측 항목은 수온 · 탁도, 유속은 향후 계측 |
| 침전수 탁도 전망 | 실측 12시간 + 모의조건 적용 6시간 전망과 불확도 구간, 관리목표선 |
| 운영 권고 | 예측 탁도, 단락류, 밀도류, 학습범위 이탈 여부에 따른 권고 |
| 모의 이력 · 작업 큐 | 서로게이트 실행과 정밀 CFD(용역사) 요청 이력 |
| 모델 상태 | 운영 모델(POD 기반), 비교 모델(MeshGraphNets, 섀도 운영), 학습 데이터 구성, 실측 대비 편차 |

## 전제한 업무 흐름

```
실측 수온 · 탁도 (물종합진단처)
   → CFD 기준모델 보정 · 검증, 설계조건 모의 (용역사)
   → CFD 모의 설계, 서로게이트 학습 · 배포 (AI연구소)
   → 본 대시보드에서 상시 감시 · 수시 모의
   → 학습범위 밖 조건은 정밀 CFD로 검증 후 재학습
```

## 가정

- 침전지 제원: L 80 m × W 20 m (표면적 1,600 m²)
- 침전수 탁도 관리목표: 2.0 NTU (설정값)
- 학습 데이터: CFD 60회(학습 40 · 조정 10 · 시험 10) + 추가 3회
- 정밀 CFD 1회 계산시간: 용역사 확인 필요
